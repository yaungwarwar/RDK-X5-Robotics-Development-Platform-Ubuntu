# Phase B.4 — unified local QA and provenance

Run the complete workstation validation with `./scripts/qa-full.sh`; configuration, required-stage behavior and output locations are in the [unified QA guide](UNIFIED_QA_GUIDE.md). The command uses the existing process guard and proxy validation, runs Python tests once, builds both frontends before their browser tests, checks served HTML and JavaScript against those builds, and verifies sources and outputs remain unchanged during testing. It rejects occupied ports, detects startup/ownership failures, stops only owned services, checks cleanup, and verifies the original release and laboratory bundle hashes before and after the run. Missing requirements or required skips fail the run.

## Actual final run

The final unified run passed **267 Python tests, 16 dashboard browser tests and 16 laboratory browser tests: 299 unique tests**, with **zero failures and zero skips**. Python, both TypeScript checks, both lint checks, formatting, compilation, strict pip check and both fresh builds passed. Both Compose compatibility profiles, real Nginx configurations/proxy, API/WebSocket/security checks, listener ownership and cleanup passed. The structured [QA report](../qa-results/qa-report.json) records tool versions, stage durations, individual test counts, artifact hashes and owned socket evidence; its unique run directory contains JUnit and Playwright details. It is local operational output and should be reviewed before sharing.

Warnings: existing Starlette TestClient deprecation, unavailable pip cache due to local permissions, and non-failing Playwright color-environment warnings. The persistent wheel directory exists and is checked but is not used for installation during QA. No optional checks were selected.

The first unified attempt failed Nginx config testing because Nginx could not reopen captured `/dev/stderr`; the transient QA config now uses a temporary error log. During runner regression additions, Ruff correctly caught a partial executable path and a formatting error; both were fixed. A subsequent repeat exposed the occupied-port fixture's plain bind encountering TCP reuse state after a prior run; the fixture now enables address reuse while retaining the actual occupied listener. The final run passed after those corrections. No failed intermediate attempt is counted as a pass.

The B.3 report now correctly records high-detail baseline median **22.577 ms CPU** and **22.592 ms wall**, preserving its raw benchmark data; the benchmark was not rerun for that correction.
